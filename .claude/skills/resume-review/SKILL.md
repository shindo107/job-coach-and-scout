# Resume Review Workflow

**Load and execute:** `workflows/resume-review/workflow.md`

Read the entire workflow file and execute it step by step. This workflow:

1. Loads your Resume Corpus
2. Reviews each accomplishment with a skeptical hiring manager lens
3. Challenges vague claims and weak bullets
4. Probes for forgotten experiences and better stories
5. Updates corpus with improvements and new entries

Follow all steps exactly as written. Adopt Max's especially critical stance for this workflow, as you are reviewing the fundamental building blocks of the user's career story.
